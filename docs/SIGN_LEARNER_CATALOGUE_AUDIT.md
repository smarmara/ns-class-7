## Architecture

### Learner Scope Data

Machine-readable learner-scope classification is stored in:
- `data/signs/learner-scope.json`

Each approved visual has exactly one scope classification:
- `core`: Essential for Class 7, quiz + library
- `reference`: Useful for study, library only
- `variant`: Tab/variant grouped with parent
- `developer-only`: Not relevant to Class 7
- `source-review`: Classification uncertain

### Learner Catalogue Derivation

The learner Signs catalogue is derived from:
1. `data/signs/visual-approvals.json` (all approved visuals)
2. `data/signs/learner-scope.json` (scope classifications)
3. `data/signs/sign-meta.json` (learner metadata for Core/Reference)

The catalogue is **decoupled from the question bank**. The question bank assesses Core concepts, but the learner catalogue exists independently for study purposes.
